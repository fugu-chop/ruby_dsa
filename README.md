# Ruby Data Structures and Algorithms

A repo to house Ruby-flavoured data structures and algorithms code.

# Testing

Tests can be run with `bundle exec rspec`.

Debugging through VSCode is enabled via:

1. Generating the RSpec binstubs (`bundle binstubs rspec-core`)

2. Using the current settings in `.vscode/launch.json`

3. Setting a breakpoint and using `RSpec with rdbg` in `Run and Debug` within the VS Code UI

Further information can be found [here](https://github.com/ruby/vscode-rdbg/issues/410).
